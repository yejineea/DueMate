# DueMate PRD

> v1(2026-10): 과제 관리, 우선순위 추천, 과부하 경고, 캘린더, 통계, 성적
> v2(2026-11): 화면 정리, 공부 가능 시간 자동 계산, 뽀모도로, 예상 시간 자동 추정·보정, 토마토 키우기

## 1. 제품 개요

DueMate는 할 일이 많은 대학생 대신 **"지금 무엇부터 할지"를 결정해 주는** 과제·일정 관리 웹 앱이다. 과제 개수가 아니라 실제 남은 작업 시간과 마감까지 쓸 수 있는 시간을 비교해 우선순위를 정하고, 뽀모도로로 바로 실행하게 한다.

## 2. 문제 정의

- 여러 과목의 마감이 겹칠 때 무엇부터 해야 할지 판단하기 어렵다.
- 과제 개수만으로는 실제 부담을 알 수 없다.
- 수업·아르바이트 때문에 쓸 수 있는 공부 시간이 제한적이다.

### v1 사용 후 드러난 문제 (v2에서 해결)

| 문제 | v2 해결 |
| --- | --- |
| 첫 화면이 산만해 "지금 할 일"이 눈에 띄지 않음 | 뽀모도로 탭: 지금 할 일 슬라이드 + 타이머 + 오늘 계획만 |
| 공부 가능 시간·예상 소요 시간을 매번 직접 입력 | 일정으로 공부 가능 시간 자동 계산, 유형·난이도로 예상 시간 자동 추정 |
| 추천을 받아도 실행으로 이어지지 않음 | 과제별 뽀모도로 타이머, 집중 시간 자동 기록 |
| 계속 쓰게 만드는 동기가 없음 | 토마토 키우기(주간 목표·성장 단계·배지) |

## 3. 목표 사용자

여러 과목의 과제와 시험을 병행하며, 수업·아르바이트 사이 제한된 시간 안에서 계획을 세워야 하는 대학생.

## 4. 핵심 가치

1. **결정 대행**: 우선순위와 남은 빈 시간으로 "지금 할 일"과 오늘의 🍅 계획을 제시한다.
2. **자동 계산, 최종 결정은 사용자**: 공부 가능 시간·예상 시간·오늘 계획은 자동으로 계산하되, 언제든 직접 고칠 수 있다.
3. **바로 실행**: 과제별 뽀모도로로 시작하고, 집중 시간은 자동으로 기록되어 다음 계산에 반영된다.
4. **쓸수록 정확해짐**: 실제 작업 시간으로 예상 시간을 보정한다.
5. **꾸준함의 동기**: 모은 🍅로 토마토를 키우고 배지를 모은다.

## 5. 사용자 시나리오

학생이 처음 한 번 수업·알바 일정을 매주 반복으로 등록한다. 과제를 추가할 때는 마감·유형·난이도만 고르면 예상 시간이 자동으로 채워진다. 앱을 열면 뽀모도로 탭 가운데에 지금 할 과제와 큰 타이머가 있고, 오른쪽에는 남은 빈 시간대에 배치된 오늘 계획이 있다. 학생은 ▶ 시작으로 25분 집중하고, 끝나면 단계 완료 여부를 체크한다. 과제를 끝내면 실제 걸린 시간이 예상 시간 보정에 쓰이고, 이번 주 모은 🍅만큼 토마토가 자란다.

## 7. 비기능 요구사항

- 서버 없이 브라우저 `localStorage`에 저장한다. 실행 환경은 브라우저로 한정한다.
- 빌드 도구 없이 `index.html`을 열거나 GitHub Pages에서 바로 실행된다.
- 데스크톱과 휴대폰(390px) 화면, 라이트·다크 테마를 지원한다.
- v1 데이터(localStorage, JSON 백업)를 v2에서 그대로 불러온다.
- 핵심 계산과 화면 조작은 브라우저 테스트 페이지(`tests.html`)로 검증한다.

## 8. 범위와 성공 기준

로그인·서버 동기화·공동 작업은 범위에서 제외한다.

- 앱을 열면 스크롤 없이 지금 할 일·타이머·오늘 계획이 보인다.
- 일정만 등록하면 공부 가능 시간이 계산되고, 계산 근거를 표로 확인할 수 있다.
- 과제 입력 시 예상 시간을 직접 넣지 않아도 되고, 완료 기록이 쌓일수록 예상이 내 속도에 맞춰진다.
- 한 번의 클릭으로 뽀모도로를 시작하고, 집중 시간이 과제에 기록된다.
- v1 데이터가 유지되고 테스트 페이지의 모든 테스트가 통과한다.
