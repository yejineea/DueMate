# DueMate PRD

> v1(2026-10): 과제 관리, 우선순위 추천, 과부하 경고, 캘린더, 통계, 성적
> v2(2026-11): 화면 정리, 공부 가능 시간 자동 계산, 뽀모도로 타이머

## 1. 제품 개요

DueMate는 대학생이 과제, 시험, 개인 일정을 한 곳에서 관리하도록 돕는 웹 앱이다. 과제 수가 아닌 실제 작업 시간과 마감 위험도를 기준으로 우선순위를 제안하고, **"지금 무엇을 할지"를 대신 결정해 준다.**

## 2. 문제 정의

- 여러 과목의 마감이 겹칠 때 무엇부터 해야 할지 판단하기 어렵다.
- 과제 개수만으로는 실제 부담을 알 수 없다.
- 수업·아르바이트 때문에 쓸 수 있는 공부 시간이 제한적이다.

### v1 사용 후 드러난 문제 (v2에서 해결)

- **화면이 산만하다.** 대시보드에 통계 카드, 주간 차트, 4주 차트, 추천, 마감 목록이 한꺼번에 있어 정작 "지금 할 일"이 눈에 잘 띄지 않는다.
- **공부 가능 시간을 직접 입력해야 한다.** 요일별 시간을 사용자가 어림잡아 넣어야 했고, 시간표에 수업·알바를 등록해도 계산에 반영되지 않았다. 마감 전 가용 시간도 "09~24시에 고르게 분포"한다고 가정해 실제 빈 시간과 달랐다.
- **추천을 받은 뒤 실행으로 이어지지 않는다.** 추천 과제를 보고도 바로 시작할 장치가 약했고, 스톱워치는 집중·휴식 리듬을 잡아주지 못했다.

## 3. 목표 사용자

여러 과목의 과제와 시험을 병행하며, 제한된 시간 안에서 학습 계획을 세우려는 대학생.

## 4. 핵심 가치

1. **결정 대행**: 마감 임박도, 남은 작업량, 중요도, 난이도를 종합해 "지금 할 일 1개"와 오늘 계획을 제시한다.
2. **현실적인 시간 계산**: 시간표와 생활 시간을 빼고 남은 실제 빈 시간으로 공부 가능 시간을 자동 계산한다.
3. **바로 실행**: 추천 과제에서 뽀모도로를 바로 시작하고, 집중 시간은 자동으로 기록된다.
4. **과부하 감지**: 마감 전까지 필요한 작업량이 가용 시간을 넘으면 경고한다.

## 5. 사용자 시나리오

시험기간의 학생이 처음 한 번 수업·아르바이트 시간표와 하루 활동 시간(예: 09:00~24:00)을 등록한다. 과제와 시험을 추가하면 DueMate가 요일별 공부 가능 시간을 자동으로 계산한다. 앱을 열면 "오늘" 화면 맨 위에 지금 할 과제 1개와 이유가 보이고, 그 아래에 남은 빈 시간대에 배치된 오늘의 뽀모도로 계획이 보인다. 학생은 버튼 하나로 25분 집중을 시작하고, 집중이 끝나면 작업 시간이 과제에 자동 기록되며 남은 작업량과 추천 순위가 갱신된다.

## 7. 비기능 요구사항

- 서버 없이 브라우저 `localStorage`에 데이터를 저장한다. 실행 환경은 브라우저로 한정한다.
- 빌드 도구 없이 `index.html`을 열거나 GitHub Pages에서 바로 실행된다.
- v1 데이터(localStorage, JSON 백업)는 v2에서 그대로 불러올 수 있어야 한다.
- 핵심 계산(공부 가능 시간, 오늘 계획, 뽀모도로 상태 전이, 우선순위, 성적)은 브라우저 테스트 페이지로 검증한다.

## 8. 범위와 성공 기준

이번 버전은 개인 브라우저에서 동작하는 학업 관리에 집중하며, 로그인·서버 동기화·공동 작업은 범위에서 제외한다.

- 앱을 열면 스크롤 없이 "지금 할 일"과 시작 버튼이 보인다.
- 시간표를 등록하면 공부 가능 시간이 직접 입력 없이 계산되고, 계산 근거(활동·고정·생활 시간)를 확인할 수 있다.
- 추천 과제에서 한 번의 클릭으로 뽀모도로를 시작할 수 있고, 집중 완료 시 실제 작업 시간이 기록된다.
- v1에서 저장한 데이터가 v2에서 유지되고, 테스트 페이지의 모든 테스트가 통과한다.
