# DueMate PRD

## 1. 제품 개요

DueMate는 대학생이 과제, 시험, 개인 일정을 한 곳에서 관리하도록 돕는 웹 앱이다. 과제 수가 아닌 실제 작업 시간과 마감 위험도를 기준으로 우선순위를 제안한다.

## 2. 문제 정의

- 여러 과목의 마감이 겹칠 때 무엇부터 해야 할지 판단하기 어렵다.
- 과제 개수만으로는 실제 부담을 알 수 없다.
- 수업·아르바이트 때문에 쓸 수 있는 공부 시간이 제한적이다.

## 3. 목표 사용자

여러 과목의 과제와 시험을 병행하며, 제한된 시간 안에서 학습 계획을 세우려는 대학생.

## 4. 핵심 가치

1. 마감 가시화: 오늘과 이번 주의 마감을 빠르게 파악한다.
2. 우선순위 추천: 마감 임박도, 남은 작업량, 중요도, 난이도를 종합한다.
3. 과부하 감지: 주간 과제량과 공부 가능 시간을 비교해 경고한다.

## 5. 기능 요구사항

| 우선순위 | 기능 | 설명 |
| --- | --- | --- |
| P1 | 과제 관리 | 과제 생성·수정·삭제, 하위 작업, 완료 상태 |
| P1 | 우선순위 엔진 | 마감·작업량·중요도·난이도 기반 점수와 추천 이유 |
| P1 | 대시보드 | 오늘 마감, 추천 작업, 과부하 경고, 주간 요약 |
| P2 | 일정 관리 | 월간/주간 캘린더와 마감 겹침 표시 |
| P2 | 작업 기록 | 과제별 타이머와 실제 작업 시간 누적 |
| P2 | 통계·성적 | 완료율, 과목별 통계, 평가 항목 기반 성적 계산 |
| P2 | 설정·백업 | 공부 가능 시간, 시간표, 테마, JSON/CSV 내보내기 |

## 6. 비기능 요구사항

- 서버 없이 브라우저 `localStorage`에 데이터를 저장한다.
- 데스크톱과 모바일 브라우저에서 사용할 수 있어야 한다.
- 중요한 데이터는 JSON 내보내기와 가져오기로 백업할 수 있어야 한다.
